# Rota Escolar — demonstração

Protótipo responsivo para apresentar a organização de viagens escolares, cadastro de viagens e chamada separada por horário e sentido.

## Executar

Abra `index.html` no navegador ou publique o diretório no Vercel como projeto sem framework e sem comando de build.

Os dados são fictícios e ficam apenas no armazenamento local do navegador. Não há login real, banco de dados compartilhado, sincronização, controle de acesso ou garantia de segurança para informações de crianças. Não use dados reais nesta versão. Para uso operacional é necessário implementar autenticação, permissões, banco de dados e proteção apropriada.
